## 3D Developer Portfolio 🚀

A modern interactive 3D developer portfolio built with React and Three.js, designed to showcase projects, skills, and creativity through immersive visuals and smooth user interactions.

This portfolio focuses on performance, responsiveness, and clean UI, while integrating real-time 3D scenes to create a memorable user experience.

## ✨ Features

Interactive 3D scenes and animations using Three.js

Built with react-three-fiber and @react-three/drei

Smooth section transitions and motion effects

Responsive design for desktop and mobile devices

Project showcase with descriptions and external links

Contact section with a clear call-to-action

Clean and scalable component structure

## 🧰 Tech Stack

Frontend: React + Vite

3D & Graphics: Three.js, @react-three/fiber, @react-three/drei

Animations: Framer Motion

Styling: Tailwind CSS

Tooling: Git, GitHub, npm

## 📦 Installation & Setup

Clone the repository and install dependencies:

npm install


Run the development server:

npm run dev


Build for production:

npm run build



## 📁 Project Structure
src/
 ├─ components/        # Reusable UI components
 
 ├─ components/canvas/ # 3D canvas and Three.js scenes
 
 ├─ assets/            # Images and static assets
 
 ├─ constants/         # Static data and configs
 
 └─ styles/            # Global and component styles
 

## 🎯 Purpose

This project was created to:

Demonstrate practical usage of React with Three.js

Showcase frontend architecture and component design

Present projects in a visually engaging, non-traditional format
